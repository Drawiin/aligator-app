# STUDY files are personal, not project-owned

`STUDY*.md` files are the operator's personal, git-ignored notes — explicitly
distinct from the project-owned, git-tracked state surface. Project state,
decisions, and agent output belong in `.ai/state/` and `.ai/memory/`
(formerly `.project/`), never in STUDY files. Applies whenever recording
plans, state, or decisions.

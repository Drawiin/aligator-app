# Prefer computation over inference

Rely on computation (deterministic scripts, CLIs) as much as possible instead
of inference (LLM work) — it reduces cost and improves reliability. Reach for
inference only when deterministic mapping fails. Applies when choosing how to
lint, test, format, gather context, summarize, or orchestrate simple steps.

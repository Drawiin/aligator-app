# Worker never certifies its own work

The builder must not certify its own work (*Independent Judge*). A judge in a
fresh context — preferably without write/edit tools — verifies against explicit
criteria; an inferential PASS needs evidence (test output, file:line, sensor
log), never a bare assertion. Applies to every worker/validator pairing.
